Merkez, depo ve vinç kendi bağlamsal penceresine gider. **Yaklaş** yalnız aktif limandaki ilgili tesise odaklanır. Proje levhası bağlantı/kapsam penceresini açar. Paylaşılan Node, ikinci fiziksel sunucu olarak sayılmaz.

**Görünüm ve ayarlar → Liman hareketi**:

- **Deniz yüzeyi hareketi:** dalga/akıntı zamanı, iz ve suya bağlı salınımı durdurur; seyir ve veri devam eder.
- **Güneş yansımaları:** yeni bağımsız seçenek; açıkken deniz durdurulsa da statik yüzey parlaması kalabilir.
- **Hafif gemi salınımı / Gemi izi / Gemi devriyesi:** ayrı tercihler; gemi durduğunda sürekli motor izi üretilmez.
- **Görsel hareketi duraklat / Hareket tercihi:** bütün dekoratif hareketi durdurma ve sistem/azaltılmış/tam hareket davranışı korunur.

Tercihler version1 yerel kaydına geriye uyumlu eklenir. Ayar değişimi mevcut geometriyi, doku nesnesini veya rota fazını yeniden oluşturmaz. ## Çalıştırma

Normal ürün için repo kökünde `make build`, ardından `./bin/kubeview` çalıştırın. Önceki embedded manuel paket yeni arayüzü kendiliğinden içermez; yeniden derleyin veya README'deki güvenilir `STATIC_DIR` override'ını kullanın. Gerçek kubeconfig/context ve yönetim izinleri mevcut modelde kalır; bu görsel değişiklik yazma modunu açmaz.

Hızlı frontend geliştirmesi ve yalıtılmış görsel test:

```sh
npm --prefix frontend ci
npm --prefix frontend run dev -- --port 5173
# İkinci terminal, repo kökü:
KV_UI2_URL=http://127.0.0.1:5173 KV_UI2_HEADLESS=1 \
  KV_UI2_RUN_ID=ui2-local-chromium node frontend/e2e/ui2-reference.mjs
KV_UI2_URL=http://127.0.0.1:5173 KV_UI2_HEADLESS=1 KV_UI2_BROWSER=webkit \
  KV_UI2_RUN_ID=ui2-local-webkit node frontend/e2e/ui2-reference.mjs
```

`RUN_ID` benzersiz olmalıdır; mevcut kanıtın üstüne yazılmaz. `HEADLESS=1` masaüstü girişini koşudan ayırır; `BROWSER=webkit` Playwright motorudur. `KV_UI2_FACILITY_ONLY=1` yalnız kısa tesis/odak regresyonunu çalıştırır. Harness normal App'i açar, HTTP/WS'yi kendi salt okunur test verisiyle sınırlar; gerçek kümeye bağlanmaz. Yerel referans PNG yoksa hash null kaydedilir; test çalışmaya devam eder. Playwright browser kurulumu mevcut değilse frontend dizininde `npx playwright install chromium webkit` gerekir.
